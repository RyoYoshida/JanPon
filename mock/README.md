# 固定データのグラフィックモック

実ゲームとは別の70場面の表示見本。勝敗・抽選・会計・保存・実音声は実装せず、数値は固定データである。現在のゲームはルートREADMEを参照。

- プロジェクト直下で `node mock/build.mjs` を実行し、`mock/fixtures/JanPon-walkthrough.html` を開く
- 検査は `cd mock && npm test`
- 開発用サーバーは `python3 -m http.server 4173 --bind 127.0.0.1 --directory mock`
- ブラウザで `http://localhost:4173/` を開く

コインと残高の周辺で投入し、3つの手を選ぶ。初回は固定7枚、反復は固定1枚。四角4個の確認パレットから、あいこ・負け・最後の1枚・再開・別タブ・保存エラーの見本を確認する。左右矢印で場面移動、設定の閉じる・Escape・戻る/進むも確認できる。

パレットや回復候補は見本表示専用で、保存データの生成・消去を行わない。自動テストは実ブラウザ描画・実機・音声・支援技術の確認を代替しない。`proposals/JanPon-top-only.html` は初期の100灯表示比較用で、実ゲームの12窓表示とは異なる。
